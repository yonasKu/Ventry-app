## 🔧 Testing Utilities

### CSV File Generator Script (Pseudo-code)
```javascript
// Generate large attendee lists
function generateAttendees(count) {
  const attendees = [];
  for (let i = 1; i <= count; i++) {
    attendees.push({
      name: `User ${i.toString().padStart(3, '0')}`,
      email: `user${i}@test${Math.ceil(i/100)}.com`,
      phone: `555-${i.toString().padStart(4, '0')}`
    });
  }
  return attendees;
}
```

### Performance Test Data Sizes
- **Small**: 10-50 attendees (UI responsiveness)
- **Medium**: 100-500 attendees (Search performance)
- **Large**: 1000-5000 attendees (Memory usage)
- **Extra Large**: 10000+ attendees (Stress testing)

## 🚀 5-Step Setup (25 Minutes Total)

### Step 1: Create Your First Event (5 min)

1. Open Ventry app
2. Tap **"CREATE NEW EVENT"**
3. Fill in:
   - **Event Name:** "VIP Night - Saturday" or "Dinner Service - Feb 9"
   - **Category:** Select **"Restaurant/Club"**
   - **Date & Time:** Tonight's date
   - **Location:** Your venue name
   - **Expected Attendees:** Estimate (e.g., 100)

4. Tap **Save** ✓

---

### Step 2: Add Your Members/Guests (10 min)

**Option A: Import from CSV (Recommended)**
1. Export your member list to CSV format:
   ```
   Name,Email,Phone,Membership Number,VIP Status
   John Smith,john@email.com,555-0100,VIP001,Yes
   Jane Doe,jane@email.com,555-0101,REG002,No
   ```

2. In Ventry:
   - Open your event
   - Tap **"Import Attendees"**
   - Select your CSV file
   - Map columns (Name → Name, Email → Email, etc.)
   - Tap **"Import"**

**Option B: Add Manually**
1. Open your event
2. Tap **"Add Attendee"**
3. Enter:
   - Name
   - Email (optional)
   - Phone (optional)
4. Tap **"Save"**
5. Repeat for each guest

---

### Step 3: Customize Fields for Your Needs (5 min)

1. Open your event
2. Tap **"Custom Fields"**
3. Tap **"Apply Template"** → **"Restaurant/Club"**

This adds:
- ✅ Membership Number
- ✅ VIP Status (checkbox)
- ✅ Preferred Table
- ✅ Special Requests

**Want to add more?**
- Tap **"Add Field"**
- Choose type (text, number, dropdown, etc.)
- Examples:
  - "Loyalty Points" (number)
  - "Favorite Drink" (text)
  - "Dietary Restrictions" (multi-select)
  - "Member Since" (date)

---

### Step 4: Generate QR Codes (Optional, 5 min)

**For Members:**
1. Open event → Attendees list
2. Tap on a member
3. Tap **"Show QR Code"**
4. Member can screenshot and save to phone

**For Email Invitations:**
1. Export attendee list with QR codes
2. Send via email
3. Guests show QR code at door

---

### Step 5: Start Checking In! (Event Night)

**At the Door/Host Stand:**

1. Open Ventry app
2. Open your event
3. Tap **"Check-In"**

**Two Ways to Check In:**

**Method 1: QR Code Scan (Fastest - 2 seconds)**
- Tap **"Scan QR"**
- Point camera at guest's QR code
- ✓ Automatic check-in with timestamp

**Method 2: Manual Search (3-5 seconds)**
- Type guest name in search bar
- Tap their name
- Swipe **"Slide to Check In"**
- ✓ Checked in!

**Real-Time Info:**
- See total checked in: **45/100**
- See VIP status (gold badge)
- See special requests
- See table preferences

## 💡 Pro Tips for Restaurants/Clubs

### For Nightclubs:

**1. VIP Fast Lane**
- Mark VIPs with checkbox
- They show with gold badge
- Skip the line, instant check-in

**2. Capacity Management**
- Set expected attendees to fire code limit
- Watch real-time count
- Stop entry when full

**3. Guest List + Door Sales**
- Pre-add guest list members
- Add walk-ins manually at door
- Track both separately

**4. Multiple Entry Points**
- Use one device per door (for now)
- Multi-device sync coming soon!

---

### For Restaurants:

**1. Reservation Management**
- Create event for each service (Lunch, Dinner)
- Add all reservations
- Check in as guests arrive

**2. Table Preferences**
- Use custom field: "Preferred Table"
- Options: Window, Booth, Bar, Patio, Private Room
- Host sees preference instantly

**3. Special Occasions**
- Add custom field: "Occasion"
- Options: Birthday, Anniversary, Proposal, Business
- Alert kitchen/server

**4. Dietary Restrictions**
- Use multi-select field
- Options: Vegetarian, Vegan, Gluten-Free, Nut Allergy, etc.
- Kitchen sees immediately

**5. No-Show Tracking**
- After service, see who didn't show
- Export list for follow-up
- Reduce future no-shows

---

### For Private Clubs:

**1. Membership Verification**
- Add custom field: "Expiry Date"
- System shows if expired
- Deny entry with visual alert

**2. Member Tiers**
- Add custom field: "Tier"
- Options: Gold, Silver, Bronze, Trial
- Different access levels

**3. Visit Frequency**
- Track check-ins over time
- Export statistics monthly
- Identify most active members

**4. Family Memberships**
- Add custom field: "Membership Type"
- Options: Individual, Family, Corporate
- Track all family members

## 🆘 Troubleshooting

### "QR code won't scan"
- ✅ Ensure good lighting
- ✅ Hold phone steady
- ✅ Try manual search instead

### "Can't find guest in search"
- ✅ Check spelling
- ✅ Try searching by phone/email
- ✅ Add as walk-in if not in list

### "App is slow"
- ✅ Close other apps
- ✅ Restart Ventry
- ✅ Ensure device has storage space

### "Phone died during event"
- ✅ Data is saved locally
- ✅ Charge phone and continue
- ✅ Consider backup device

### "Need to check in from multiple doors"
- ✅ Currently: one device per event
- ✅ Coming soon: multi-device sync
- ✅ Workaround: use one main entrance

## 📱 What is Ventry?

Ventry is an **offline-first event check-in app** designed for small-to-medium events, clubs, and restaurants. It enables organizers to manage attendee lists and perform fast digital check-ins via list search or QR code scanning, with **complete offline functionality**.

## 🍽️ RESTAURANT & CLUB USE CASES (Detailed)

### Use Case 1: **VIP Member Check-In at Nightclub**

**Scenario:** A nightclub has 500+ VIP members. Bouncers need to verify membership quickly at the door.

**How Ventry Helps:**
1. **Pre-Event Setup:**
   - Import member list from CSV (Name, Membership Number, VIP Status, Expiry Date)
   - Use "Restaurant/Club" template with custom fields:
     - Membership Number
     - VIP Status (checkbox)
     - Preferred Table
     - Special Requests

2. **At the Door:**
   - Bouncer opens Ventry app
   - Member shows QR code on phone OR bouncer searches by name
   - Instant check-in with timestamp
   - See VIP status immediately (highlighted)
   - Track who's inside in real-time

3. **Benefits:**
   - ✅ No internet needed (works offline)
   - ✅ Fast check-in (2-3 seconds per person)
   - ✅ Prevent duplicate entries
   - ✅ Track capacity in real-time
   - ✅ Export attendance reports for analytics

**Custom Fields for Clubs:**
- Membership Number (text with validation)
- VIP Status (checkbox - shows badge)
- Member Since (date)
- Tier Level (Gold/Silver/Bronze)
- Preferred Table (dropdown)
- Special Requests (notes)

### Use Case 2: **Restaurant Reservation Management**

**Scenario:** A fine dining restaurant has 50 reservations for Saturday night. Host needs to check in guests and manage seating.

**How Ventry Helps:**
1. **Pre-Service Setup:**
   - Create event: "Saturday Dinner Service - Feb 9"
   - Add all reservations manually or import from booking system
   - Include custom fields:
     - Party Size
     - Reservation Time
     - Table Preference (Window, Booth, Patio)
     - Dietary Restrictions
     - Special Occasions (Birthday, Anniversary)

2. **During Service:**
   - Host checks in guests as they arrive
   - See reservation details instantly
   - Mark special occasions (trigger kitchen alert)
   - Track no-shows automatically
   - Monitor table turnover

3. **Post-Service:**
   - Export attendance report
   - Identify no-shows for follow-up
   - Track VIP guest frequency
   - Generate statistics for planning

**Benefits:**
- ✅ Replace paper reservation book
- ✅ Track guest preferences over time
- ✅ Identify repeat customers
- ✅ Reduce no-shows with data
- ✅ Improve service with guest history

## 📱 GETTING STARTED (Restaurant/Club)

### Step 1: Download & Setup (5 minutes)
1. Download Ventry app
2. Create first event: "VIP Night - Feb 9"
3. Select category: "Restaurant/Club"

### Step 2: Import Members (10 minutes)
1. Export member list from your system (CSV)
2. Format: Name, Email, Phone, Membership Number
3. Import into Ventry
4. Apply "Restaurant/Club" template

### Step 3: Customize Fields (5 minutes)
1. Add custom fields:
   - VIP Status (checkbox)
   - Preferred Table (dropdown)
   - Special Requests (text)
2. Save template for future events

### Step 4: Test Check-In (5 minutes)
1. Generate QR codes for test members
2. Practice scanning
3. Practice manual search
4. Verify data appears correctly

### Step 5: Go Live! (Event Night)
1. Open event on device
2. Start checking in guests
3. Monitor capacity
4. Export report after event

**Total Setup Time: 25 minutes**

## 🆘 COMMON QUESTIONS (Restaurant/Club)

### Q: Can I use this for daily operations?
**A:** Yes! Create recurring events or one event per day.

### Q: How do I handle walk-ins without QR codes?
**A:** Use the search function - type name and check in manually.

### Q: Can I track loyalty points?
**A:** Yes! Use custom number field for points/visits.

### Q: What if my phone dies?
**A:** Data is saved locally. Charge phone and continue. Consider backup device.

### Q: Can multiple staff use the app?
**A:** Currently one device per event. Multi-device sync coming soon!

### Q: How do I prevent fake QR codes?
**A:** QR codes include unique attendee ID. System validates before check-in.

### Q: Can I integrate with my POS system?
**A:** Not yet, but API integration is planned for future release.
